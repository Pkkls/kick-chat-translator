# Kick Chat Translator

Διάβασε το chat οποιουδήποτε stream στο Kick στη δική σου γλώσσα και απάντησε στη γλώσσα του καναλιού.<br>
Δωρεάν, χωρίς λογαριασμό, χωρίς ρυθμίσεις. 43 γλώσσες, στο chat και στην ίδια την επέκταση.

## Πώς λειτουργεί

1. Εγκατέστησέ την και άνοιξε οποιοδήποτε stream στο Kick. Μια πράσινη μπάρα πάνω στο chat δείχνει ότι είναι
   ενεργή.
2. Κάθε μήνυμα παίρνει τη μετάφρασή του ακριβώς από κάτω μόλις φτάσει, στη γλώσσα του προγράμματος περιήγησής
   σου. Και στα ζωντανά stream και στις επαναλήψεις VOD.
3. Γράψε μια απάντηση στη δική σου γλώσσα. Μια προεπισκόπηση πάνω από το πλαίσιο του chat τη δείχνει στη γλώσσα
   του καναλιού: πάτα Tab ή κάνε κλικ πάνω της και αυτή η εκδοχή αντικαθιστά ό,τι έγραψες.

Η γλώσσα του καναλιού διαβάζεται από το ίδιο το Kick, οπότε δεν χρειάζεται να ρυθμίσεις τίποτα. Και οι δύο
γλώσσες αλλάζουν από τις ρυθμίσεις, και η γλώσσα ανάγνωσης μπορεί να απομνημονεύεται ξεχωριστά για κάθε κανάλι.

## Τι παίρνεις

- **43 γλώσσες**, και γλώσσες που γράφονται από δεξιά προς τα αριστερά (αραβικά, εβραϊκά, περσικά), με τις
  περιφερειακές παραλλαγές ξεχωριστές (βραζιλιάνικα και ευρωπαϊκά πορτογαλικά, απλοποιημένα και παραδοσιακά
  κινεζικά, καντονέζικα)
- **Η επέκταση τις μιλάει κι αυτή**: ρυθμίσεις, αναδυόμενο παράθυρο και μπάρα του chat και στις 43, με επιλογή
  από μενού με σημαίες
- **Δωρεάν από την πρώτη στιγμή** με το Google Translate. Πρόσθεσε το δικό σου δωρεάν κλειδί DeepL για καλύτερες
  ευρωπαϊκές γλώσσες· το MyMemory και το Lingva παίρνουν τη σκυτάλη όταν αποτυγχάνει μια μηχανή
- **Μετάφραση στη συσκευή** σε Chrome και Edge όπου την προσφέρει το πρόγραμμα περιήγησης: 22 ms αντί για 1,6 s,
  και το κείμενο δεν φεύγει ποτέ από τον υπολογιστή σου
- **Φίλτρα**: παράλειψη bots, σίγαση χρηστών ή καναλιών, απόκρυψη γραμμών που περιέχουν μια λέξη, μετάφραση μόνο
  των γλωσσών που διαλέγεις
- **Φτιαγμένο για γρήγορα chat**: τα emotes του 7TV μένουν όπως είναι, το spam από emoji και οι σύνδεσμοι
  αφαιρούνται πριν σταλεί οτιδήποτε, γλωσσάριο για ονόματα που οι μηχανές κατακρεουργούν, cache μεταφράσεων
- **Τέσσερα στυλ εμφάνισης**: κάτω από το μήνυμα, στην ίδια γραμμή, στη θέση του ή μόνο στο πέρασμα του δείκτη
- **Παύση ενός καναλιού** από τη μπάρα του chat χωρίς να σταματήσουν τα υπόλοιπα. Η αλλαγή καναλιού ή η
  ενημέρωση της επέκτασης αφήνει τις ανοιχτές καρτέλες να μεταφράζουν, χωρίς επαναφόρτωση
- Chrome, Brave, Edge και Firefox

## Μηχανές μετάφρασης

Τέσσερις πάροχοι σε αλυσίδα: όταν αποτυγχάνει ένας, παίρνει τη σκυτάλη ο επόμενος. Τη σειρά την ορίζεις εσύ.

| Πάροχος | Κλειδί | Σημείωση |
|---|---|---|
| Google | κανένα | η προεπιλογή, δουλεύει αμέσως |
| DeepL | δωρεάν | η καλύτερη ποιότητα, [δωρεάν κλειδί](https://www.deepl.com/pro-api) για 1 εκατομμύριο χαρακτήρες τον μήνα |
| MyMemory | κανένα | εφεδρικός |
| Lingva | κανένα | εφεδρικός, σε δημόσιο διακομιστή εκτός αν δείξεις τον δικό σου |

Ο ενσωματωμένος μεταφραστής του Chromium είναι ταχύτερος από όλους. Μετρήθηκε σε ζωντανό κανάλι: 22 ms από την
εμφάνιση ενός μηνύματος μέχρι τη μετάφρασή του στην οθόνη, έναντι 1618 ms μέσω της αλυσίδας cloud, χωρίς δίκτυο
και χωρίς όριο χρήσης. Το Chrome και το Edge 138 και νεότερα μπορούν να τον προσφέρουν, αν και όχι κάθε
αντίγραφο, και για κάθε ζεύγος γλωσσών το μοντέλο πρέπει να κατεβεί μία φορά, με ένα κλικ από τη μπάρα. Το
Firefox δεν τον έχει. Όπου λείπει, η αλυσίδα cloud παίρνει τη σκυτάλη και τίποτα δεν χαλάει.

## Ρυθμίσεις

Κάνε κλικ στο γρανάζι της μπάρας του chat ή δεξί κλικ στο εικονίδιο της επέκτασης και διάλεξε «Επιλογές».

- **Πάροχοι**: σειρά μηχανών, το κλειδί DeepL και ο τρόπος: πρώτα στη συσκευή, πρώτα cloud ή μόνο στη συσκευή
- **Εμφάνιση**: γλώσσα προορισμού, στυλ εμφάνισης, αρχικό κείμενο και σήμα γλώσσας, μέγεθος κειμένου, διάστιχο,
  γραμματοσειρά, χρώμα έμφασης, θέμα συνομιλίας, η προεπισκόπηση μηνύματος και τι κάνει το κλικ πάνω της
- **Φίλτρα**: bots, χρήστες, κανάλια, λέξεις-κλειδιά, γλώσσες πηγής και ένα γλωσσάριο αντικαταστάσεων
- **Για προχωρημένους**: μέγεθος και διάρκεια ζωής της cache, ταυτόχρονα αιτήματα, όριο ρυθμού ανά κανάλι,
  αντίγραφο ασφαλείας και επαναφορά
- **Δραστηριότητα**: μεταφρασμένα μηνύματα, επιτυχίες cache, κάθε γλώσσα που εμφανίστηκε στο chat και γιατί
  καθεμία από τις τελευταίες 50 γραμμές μεταφράστηκε ή αφέθηκε ως έχει
- **Πληκτρολόγιο**: το Alt+T ενεργοποιεί ή απενεργοποιεί τη μετάφραση του chat, το Alt+W την προεπισκόπηση μηνύματος
- Το κουμπί γλώσσας στη γραμμή ενεργειών του chat: ένα κλικ εναλλάσσει ανάμεσα στη γλώσσα του καναλιού και την
  τελευταία σου επιλογή, παρατεταμένο πάτημα ανοίγει τη λίστα και δύο γράμματα τη φιλτράρουν

## Συχνές ερωτήσεις

**Τα μηνύματα δεν μεταφράζονται.**
Άνοιξε την καρτέλα Δραστηριότητα στις ρυθμίσεις και πάτα «Ανάγνωση αποφάσεων»: δείχνει τις τελευταίες 50
γραμμές και γιατί καθεμία μεταφράστηκε ή αφέθηκε ως έχει. Οι περισσότερες γραμμές που παραλείπονται
παραλείπονται επίτηδες. Σε μια ζωντανή συνεδρία, 213 από τις 234 ήταν ο ίδιος χρήστης που επαναλαμβανόταν, 9
ήταν πολύ σύντομες, 7 ήταν μόνο emoji ή γέλια και 1 ήταν ήδη στη γλώσσα ανάγνωσης. Αν η καρτέλα δεν δείχνει
τίποτα, η επέκταση δεν βλέπει το chat: άνοιξε ένα issue.

**Η πράσινη μπάρα εξαφανίστηκε.**
Ανανέωσε τη σελίδα. Αν ξανασυμβεί, άνοιξε ένα [issue](https://github.com/Pkkls/kick-chat-translator/issues)
με το κανάλι και τι έκανες πριν.

**Πώς παίρνω καλύτερες μεταφράσεις;**
Πρόσθεσε ένα δωρεάν κλειδί DeepL στις ρυθμίσεις. Το δωρεάν πλάνο καλύπτει ένα εκατομμύριο χαρακτήρες τον μήνα και
το DeepL ξοδεύεται μόνο στα ζεύγη γλωσσών όπου κερδίζει τις δωρεάν μηχανές.

**Ποιο στυλ εμφάνισης να διαλέξω;**
Κάτω από το μήνυμα. Τα άλλα τρία δουλεύουν, αλλά ακόμη βελτιώνονται.

**Μπορώ να χρησιμοποιήσω την επέκταση στη γλώσσα μου;**
Ναι. Ακολουθεί τη γλώσσα του προγράμματος περιήγησής σου και το μενού στην κορυφή των ρυθμίσεων την αλλάζει σε
οποιαδήποτε από τις 43.

**Δουλεύει στις επαναλήψεις VOD;**
Ναι, με τον ίδιο τρόπο όπως στα ζωντανά stream.

**Χάλασε μετά από ενημέρωση του Kick.**
Το Kick αλλάζει κατά καιρούς τον τρόπο που είναι χτισμένο το chat του. Άνοιξε ένα [issue](https://github.com/Pkkls/kick-chat-translator/issues)
και θα διορθωθεί.

**Το φτιάχνει το Kick;**
Όχι. Είναι ανεξάρτητο έργο ανοιχτού κώδικα, χωρίς σχέση με το Kick.

## Ανάπτυξη

```bash
git clone https://github.com/Pkkls/kick-chat-translator.git
cd kick-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

Τα builds είναι αναπαραγώγιμα: το ίδιο commit δίνει zip πανομοιότυπα byte προς byte σε οποιοδήποτε μηχάνημα, κάτι
που ελέγχεται χτίζοντας ένα `git archive` του tag σε κενό φάκελο και συγκρίνοντας τα hashes.

Πέρα από τα unit tests, 42 offline έλεγχοι φορτώνουν την έτοιμη επέκταση σε πραγματικό πρόγραμμα περιήγησης, την
οδηγούν και επιβεβαιώνουν τι κάνει, με τη σελίδα να σερβίρεται τοπικά και τη μηχανή μετάφρασης να απαντά τοπικά.
Χρειάζονται το Playwright, που εσκεμμένα δεν είναι εξάρτηση: δείξε το `UX_KIT` σε φάκελο του οποίου το
`node_modules` το περιέχει, ή τρέξε `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all 42, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

Τα κείμενα της διεπαφής βρίσκονται στο `src/shared/i18n/` (αναδυόμενο παράθυρο και ρυθμίσεις, με κλειδί το
αγγλικό κείμενο) και στο `src/content/i18n/` (μπάρα του chat, με κλειδί το id και το αγγλικό κείμενο ως
εφεδρικό), ένα αρχείο ανά γλώσσα· τα tests απαιτούν από κάθε αρχείο το πλήρες σύνολο κλειδιών. Τα κείμενα για τα
store βρίσκονται στο [store/](store/) και μια έκδοση είναι ένα tag έκδοσης: το CI τη χτίζει, την ελέγχει και τη
δημοσιεύει και στα δύο store.

Στοίβα: Manifest V3, Vite, TypeScript, Preact, Tailwind.
