# Kick Chat Translator

Читайте чат будь-якого стріму на Kick своєю мовою й відповідайте мовою каналу.<br>
Безкоштовно, без акаунта, нічого налаштовувати не треба. 43 мови, і в чаті, і в самому розширенні.

## Як це працює

1. Установіть розширення й відкрийте будь-який стрім на Kick. Зелена смуга вгорі чату показує, що воно
   ввімкнене.
2. Кожне повідомлення отримує переклад одразу під собою, щойно надходить, мовою вашого браузера. І на
   прямих ефірах, і на записах VOD.
3. Напишіть відповідь своєю мовою. Попередній перегляд над полем введення покаже її мовою каналу: натисніть Tab
   або клацніть по ньому, і цей варіант замінить набраний текст.

Мову каналу розширення бере в самого Kick, тож налаштовувати нічого не треба. Обидві мови змінюються в
налаштуваннях, а мову читання можна запам'ятовувати окремо для кожного каналу.

## Що ви отримуєте

- **43 мови**, зокрема з письмом справа наліво (арабська, іврит, перська); регіональні варіанти не
  змішуються (бразильська й європейська португальська, спрощена й традиційна китайська, кантонська)
- **Розширення розмовляє ними теж**: налаштування, спливне вікно й панель чату всіма 43 мовами, вибір із меню
  з прапорами
- **Безкоштовно одразу** з Google Translate. Додайте свій безкоштовний ключ DeepL для кращого перекладу
  європейськими мовами; MyMemory і Lingva підхоплюють, коли якийсь рушій відмовляє
- **Переклад на пристрої** в Chrome і Edge, де браузер його пропонує: 22 мс замість 1,6 с, а текст
  ніколи не залишає ваш комп'ютер
- **Фільтри**: пропускати ботів, глушити користувачів або канали, ховати рядки з певним словом,
  перекладати лише вибрані вами мови
- **Створено для швидких чатів**: емоути 7TV залишаються як є, спам емодзі й посилання вирізаються до того, як
  щось буде надіслано, глосарій для імен, які рушії перекручують, кеш перекладів
- **Чотири стилі показу**: під повідомленням, у тому самому рядку, замість нього або лише при наведенні
- **Пауза для одного каналу** просто з панелі чату, решта працює далі. Зміна каналу чи оновлення
  розширення не зупиняє переклад у відкритих вкладках, перезавантажувати не треба
- Chrome, Brave, Edge і Firefox

## Рушії перекладу

Чотири сервіси, з'єднані в ланцюжок: коли один відмовляє, наступний підхоплює. Порядок задаєте ви.

| Сервіс | Ключ | Примітка |
|---|---|---|
| Google | немає | типовий, працює одразу |
| DeepL | безкоштовний | найкраща якість, [безкоштовний ключ](https://www.deepl.com/pro-api) на 1 мільйон символів на місяць |
| MyMemory | немає | запасний |
| Lingva | немає | запасний, на публічному сервері, якщо не вкажете свій |

Вбудований перекладач Chromium швидший за всі вони. Виміряно на прямому каналі: 22 мс від появи повідомлення
до його перекладу на екрані проти 1618 мс через хмарний ланцюжок, без мережі й без квоти. Chrome і Edge 138
та новіші можуть його запропонувати, хоча не кожна копія його має, а для кожної пари мов модель потрібно
завантажити один раз, одним клацанням із панелі. У Firefox його немає. Де його бракує, хмарний ланцюжок
підхоплює, і нічого не ламається.

## Налаштування

Клацніть шестірню на панелі чату або натисніть правою кнопкою на значок розширення й виберіть «Налаштування».

- **Сервіси**: порядок рушіїв, ваш ключ DeepL і режим: спершу на пристрої, спершу хмара або лише на пристрої
- **Вигляд**: мова перекладу, стиль показу, оригінальний текст і значок мови, розмір тексту, міжрядковий інтервал,
  шрифт, колір акценту, тема чату, попередній перегляд під час введення і що відбувається після клацання по ньому
- **Фільтри**: боти, користувачі, канали, ключові слова, мови оригіналу та глосарій замін
- **Додатково**: розмір і строк життя кешу, одночасні запити, ліміт запитів на канал, резервна копія та відновлення
- **Активність**: перекладені повідомлення, влучання в кеш, кожна мова, побачена в чаті, і чому кожен з останніх 50
  рядків було перекладено або залишено
- **Клавіатура**: Alt+T вмикає або вимикає переклад чату, Alt+W попередній перегляд під час введення
- Кнопка мови на панелі дій чату: одне клацання перемикає між мовою каналу й вашим останнім вибором, довге
  натискання відкриває список, а дві набрані літери його фільтрують

## Конфіденційність

Ні облікового запису, ні мого сервера, ні аналітики, якщо ви не ввімкнете щоденний анонімний підрахунок, який надсилається в Google Analytics (використані механізми, помилки, швидкість, ніколи не ваші повідомлення, імена чи канали). Повідомлення чату йдуть лише до обраного вами сервісу перекладу й
більше нікуди, а в режимі перекладу на пристрої навіть туди ні. Копія з магазину не робить жодних інших запитів.
Копія, встановлена вручну, питає GitHub про тег останньої версії щонайбільше раз на шість годин, щоб знати,
чи показувати позначку оновлення. [Докладніше](PRIVACY.md)

## Поширені запитання

**Повідомлення не перекладаються.**
Відкрийте вкладку «Активність» у налаштуваннях і натисніть «Показати рішення»: вона покаже останні 50 рядків
і чому кожен із них було перекладено або залишено. Більшість пропущених рядків пропущено навмисно. За одну
прямий ефір 213 із 234 були тим самим користувачем, що повторюється, 9 були закороткі, 7 складалися лише з емодзі
чи сміху, а 1 уже був мовою читання. Якщо вкладка взагалі порожня, розширення не бачить чату: будь ласка,
створіть issue.

**Зелена смуга зникла.**
Оновіть сторінку. Якщо повториться, створіть [issue](https://github.com/Pkkls/kick-chat-translator/issues)
з назвою каналу й тим, що ви робили перед цим.

**Як отримати кращий переклад?**
Додайте безкоштовний ключ DeepL у налаштуваннях. Безкоштовний тариф покриває мільйон символів на місяць, а DeepL
використовується лише для тих пар мов, де він перевершує безкоштовні рушії.

**Який стиль показу вибрати?**
Під повідомленням. Решта три працюють, але їх ще доопрацьовують.

**Чи можна користуватися розширенням своєю мовою?**
Так. Воно йде за мовою вашого браузера, а меню вгорі налаштувань перемикає його на будь-яку з
43.

**Чи працює воно на записах VOD?**
Так, так само, як і на прямих ефірах.

**Воно зламалося після оновлення Kick.**
Kick іноді змінює будову свого чату. Створіть [issue](https://github.com/Pkkls/kick-chat-translator/issues),
і це виправлять.

**Це зроблено в Kick?**
Ні. Це незалежний проєкт із відкритим кодом, не пов'язаний із Kick.

## Розробка

```bash
git clone https://github.com/Pkkls/kick-chat-translator.git
cd kick-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

Збірки відтворювані: той самий коміт дає побайтово однакові zip на будь-якій машині, що перевіряється збіркою
`git archive` тегу в порожній папці та порівнянням хешів.

Крім unit-тестів, 42 офлайн-перевірки завантажують зібране розширення в справжній браузер, керують ним і
перевіряють, що воно робить, причому сторінку віддають локально, а рушій перекладу відповідає локально. Їм потрібен
Playwright, який навмисно не є залежністю: вкажіть у `UX_KIT` папку, у `node_modules` якої він є,
або виконайте `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all 42, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

Рядки інтерфейсу лежать у `src/shared/i18n/` (спливне вікно й налаштування, ключ - англійський текст) і
`src/content/i18n/` (панель чату, ключ - id, англійський текст як запасний), по одному файлу на мову;
тести вимагають, щоб кожен файл мав повний набір ключів. Тексти для магазинів
лежать у [store/](store/), а випуск - це тег версії: CI збирає, перевіряє й публікує його в обох магазинах.

Стек: Manifest V3, Vite, TypeScript, Preact, Tailwind.
