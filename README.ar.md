## ماذا تفعل

افتح بثًا على Kick دردشته بلغة لا تقرأها. تحصل كل رسالة على ترجمتها أسفلها مباشرةً لحظة وصولها، في البث
المباشر وفي إعادات البث على حد سواء. اكتب ردًا فتظهر فوق مربع الدردشة معاينة بلغة القناة: اضغط Tab أو
انقر عليها، فتحل تلك النسخة محل ما كتبته.

لا شيء يحتاج إلى إعداد. تُترجم الدردشة الواردة إلى لغة متصفحك، ويخرج ما تكتبه باللغة التي تبث بها القناة،
وهي تُقرأ من Kick نفسها. ويمكن تغيير الأمرين من الإعدادات.

- ‏43 لغة، بما فيها الكتابات من اليمين إلى اليسار (العربية والعبرية والفارسية) والمتغيرات الإقليمية
  (البرتغالية البرازيلية والصينية التقليدية والكانتونية)
- يعمل Google مباشرةً، بلا مفتاح وبلا حساب. أضف مفتاح DeepL المجاني الخاص بك لجودة أعلى، مع MyMemory
  وLingva بديلين احتياطيين
- ترجمة على الجهاز في Chrome وEdge حيث يوفرها المتصفح: ‏22 ملّي ثانية بدل 1.6 ثانية، ولا يغادر النص جهازك
- رموز 7TV التعبيرية، وفلاتر للروبوتات والمستخدمين، وفلتر للكلمات المفتاحية، ومسرد للأسماء التي تشوهها
  المحركات
- أوقف قناة واحدة مؤقتًا من شريط الدردشة دون إيقاف القنوات الأخرى. وعند تبديل القناة أو تحديث الإضافة تواصل
  علامات التبويب المفتوحة الترجمة دون إعادة تحميل
- Chrome وBrave وEdge وFirefox

## التثبيت

[Chrome وBrave وEdge: سوق Chrome الإلكتروني](https://chromewebstore.google.com/detail/kick-chat-translator/nkkjmbkmacbdkboijmnhjnblcaiclhni)

[Firefox: إضافات Mozilla](https://addons.mozilla.org/firefox/addon/kick-chat-translator/)

افتح أي بث على Kick: يدل الشريط الأخضر أعلى الدردشة على أنها تعمل. النسخ المثبتة من المتاجر تتحدث تلقائيًا.

<details>
<summary>التثبيت يدويًا من ملف zip لإصدار</summary>

نزّل ملف zip الخاص بمتصفحك من [Releases](https://github.com/Pkkls/kick-chat-translator/releases/latest) وفك ضغطه.

- Chrome وBrave وEdge (`…-chromium.zip`): افتح `chrome://extensions`، وفعّل وضع المطوّر، وانقر "تحميل إضافة غير مضغوطة"، واختر المجلد.
- Firefox 121+ (`…-firefox.zip`): افتح `about:debugging#/runtime/this-firefox`، وانقر "تحميل إضافة مؤقتة"، واختر `manifest.json`.

النسخة المثبتة بهذه الطريقة لا تتحدث تلقائيًا. تُظهر أيقونتها شارة عند وجود إصدار أحدث، وتربط النافذة
المنبثقة بالمتجر.

</details>

## محركات الترجمة

أربعة مزودين في سلسلة: إذا فشل أحدهم تولى التالي. أنت من يحدد الترتيب.

| المزود | المفتاح | ملاحظة |
|---|---|---|
| Google | لا يلزم | الافتراضي، يعمل مباشرةً |
| DeepL | مجاني | أفضل جودة، [مفتاح مجاني](https://www.deepl.com/pro-api) لمليون حرف شهريًا |
| MyMemory | لا يلزم | احتياطي |
| Lingva | لا يلزم | احتياطي، على نسخة عامة ما لم توجهه إلى نسختك الخاصة |

المترجم المدمج في Chromium أسرع منها جميعًا. قيس على قناة مباشرة: ‏22 ملّي ثانية من ظهور الرسالة إلى ظهور
ترجمتها على الشاشة، مقابل 1618 ملّي ثانية عبر السلسلة السحابية، بلا شبكة وبلا حصة. قد يوفره Chrome وEdge
بدءًا من الإصدار 138، وإن لم يكن في كل نسخة، وكل زوج لغات يحتاج إلى تنزيل نموذجه مرة واحدة بنقرة من الشريط.
Firefox لا يملكه. وحيثما غاب، تتولى السلسلة السحابية الأمر ولا يتعطل شيء.

## الإعدادات

انقر على الترس في شريط الدردشة، أو انقر بزر الماوس الأيمن على أيقونة الإضافة واختر الخيارات.

- اللغة المستهدفة، ولغة قراءة تُحفظ لكل قناة إن فعّلتها
- ترتيب المزودين، ومفتاح DeepL الخاص بك، ووضع المحرك: الجهاز أولًا، أو السحابة أولًا، أو الجهاز فقط
- العرض: تحت الرسالة (موصى به)، أو بعدها في السطر نفسه، أو مكانها، أو عند تمرير المؤشر، مع خيار إظهار النص
  الأصلي وشارة لغة المصدر
- زر اللغة في شريط إجراءات الدردشة: نقرة واحدة تبدّل بين لغة القناة وآخر اختيار لك، والضغط المطوّل يفتح
  القائمة، وكتابة حرفين تصفّيها
- معاينة الكتابة: تشغيل أو إيقاف، ولغتها المستهدفة، وهل يملأ النقر عليها مربع الدردشة أم ينسخها
- الفلاتر: تخطي الروبوتات، وحظر مستخدمين أو قنوات أو كلمات مفتاحية، وتقييد لغات المصدر
- المسرد: أزواج بحث واستبدال تُطبّق على الترجمات
- الميزانية: حصة DeepL، وحد المعدل لكل قناة، وحجم ذاكرة التخزين المؤقت ومدة صلاحيتها
- سهولة القراءة والمظهر: حجم النص، وتباعد الأسطر، والخط، ولون التمييز، وسمة الدردشة
- لوحة المفاتيح: ‏Alt+T يشغّل ترجمة الدردشة أو يوقفها، وAlt+W معاينة الكتابة
- النشاط: الرسائل المترجمة، ومرات الاستفادة من الذاكرة المؤقتة، وكل لغة ظهرت في الدردشة، وسبب ترجمة كل سطر
  من آخر 50 سطرًا أو تركه
- واجهة الإضافة نفسها بالإنجليزية أو الإسبانية أو الفرنسية أو البرتغالية أو التركية أو الروسية أو العربية
  أو الصينية أو اليابانية أو الكورية

## الخصوصية

لا حساب، ولا تحليلات، ولا خادم يخصني. تذهب رسائل الدردشة إلى مزود الترجمة الذي اخترته ولا مكان غيره، وفي
وضع الترجمة على الجهاز لا تذهب حتى إليه. النسخة المثبتة من متجر لا ترسل أي طلب آخر. أما النسخة المثبتة
يدويًا فتسأل GitHub عن وسم آخر إصدار مرة كل ست ساعات على الأكثر، لتعرف هل تُظهر شارة التحديث.

## الأسئلة الشائعة

**الرسائل لا تُترجم.**
افتح تبويب النشاط في الإعدادات واضغط "Read decisions": يعرض آخر 50 سطرًا ويذكر سبب ترجمة كل منها أو تركه.
معظم الأسطر المتخطاة تُتخطى عمدًا. في جلسة بث مباشر واحدة كان 213 من 234 سطرًا تكرارًا من المستخدم نفسه،
و9 أقصر من اللازم، و7 رموزًا تعبيرية أو ضحكًا فقط، وسطر واحد كان بلغة القراءة أصلًا. إن لم يُظهر التبويب
شيئًا على الإطلاق، فالإضافة لا ترى الدردشة: افتح بلاغًا من فضلك.

**اختفى الشريط الأخضر.**
أعد تحميل الصفحة. وإن تكرر ذلك، افتح [بلاغًا](https://github.com/Pkkls/kick-chat-translator/issues) يذكر القناة
وما فعلته قبلها.

**كيف أحصل على ترجمات أفضل؟**
أضف مفتاح DeepL مجانيًا في الإعدادات. الباقة المجانية تغطي مليون حرف شهريًا، ولا يُستهلك DeepL إلا في أزواج
اللغات التي يتفوق فيها على المحركات المجانية.

**أي طريقة عرض أستخدم؟**
تحت الرسالة. الطرق الثلاث الأخرى تعمل، وما زالت قيد الضبط.

**هل تعمل في إعادات البث؟**
نعم، بالطريقة نفسها كما في البث المباشر.

**توقفت بعد تحديث في Kick.**
تغيّر Kick أحيانًا طريقة بناء دردشتها. افتح [بلاغًا](https://github.com/Pkkls/kick-chat-translator/issues) وسيُصلح
الأمر.

**هل هذه من صنع Kick؟**
لا. إنها مشروع مستقل مفتوح المصدر، لا صلة له بـ Kick.

## الجديد

### 3.0.2

زر الإيقاف المؤقت في شريط الدردشة يوقف الآن القناة التي تشاهدها فقط. في السابق كان يُوقف الترجمة في كل القنوات وكل علامات التبويب، إلى أن تعيد تشغيلها من النافذة المنبثقة.

عندما تكون قناة علامة التبويب الحالية متوقفة مؤقتًا، تُظهر النافذة المنبثقة ذلك وتعرض زر استئناف.

علامة تبويب Kick التي كانت مفتوحة أثناء تثبيت الإضافة أو تحديثها تواصل الترجمة. في السابق كانت تتوقف إلى أن تعيد تحميل الصفحة.

بعد الانتقال إلى قناة أخرى دون إعادة التحميل، كانت الترجمة تتوقف إلى أن تُحدّث الصفحة. أصبحت الآن تتبع الدردشة المعروضة.

إلى أن تُجري أول ترجمة، تقترح النافذة المنبثقة المفتوحة خارج Kick فتح قناة وتعرض زرًا لذلك.

كل إصدار، مع ما تغيّر والقياس الذي يقف خلفه:
[Releases](https://github.com/Pkkls/kick-chat-translator/releases) و[CHANGELOG.md](CHANGELOG.md).

## التطوير

```bash
git clone https://github.com/Pkkls/kick-chat-translator.git
cd kick-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

البناء قابل لإعادة الإنتاج: يعطي الالتزام نفسه ملفات zip متطابقة بايتًا ببايت على أي جهاز، ويُتحقق من ذلك
ببناء `git archive` للوسم في مجلد فارغ ومقارنة البصمات.

إلى جانب اختبارات الوحدات، تحمّل 41 بوابة غير متصلة الإضافة المبنية في متصفح حقيقي، وتقودها وتتحقق مما
تفعله، مع صفحة تُقدَّم محليًا ومحرك ترجمة يُجاب محليًا. تحتاج إلى Playwright، الذي ليس اعتمادية عن قصد:
وجّه `UX_KIT` إلى مجلد يحتوي `node_modules` الخاص به عليه، أو شغّل `npm i -D playwright`.

```bash
node test/e2e/run-gates.mjs --headless                  # all 41, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

التقنيات: Manifest V3 وVite وTypeScript وPreact وTailwind. نصوص المتاجر موجودة في [store/](store/)، والإصدار
هو وسم نسخة: يبنيه CI ويفحصه وينشره في المتجرين.
