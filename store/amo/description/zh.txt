Kick Chat Translator 是一款免费的 Kick 直播聊天翻译扩展。用你自己的语言阅读任何直播的聊天，并直接在聊天框里用频道的语言回复。

在看土耳其语、西班牙语、俄语或阿拉伯语的直播，却看不懂聊天？安装后打开直播，每条消息一到，正下方就会出现它的译文。无需账号，无需 API 密钥，什么都不用设置。

使用方法

1. 打开任意 Kick 直播。聊天区顶部的绿色条表示翻译器已开启。
2. 每条新消息下方都会显示译文，语言为你浏览器的语言。
3. 用你自己的语言输入回复。预览会以频道的语言显示它：按 Tab 或点击预览，然后发送。

频道的语言从 Kick 自身读取，两种语言都可以在设置里更改。直播和 VOD 回放都能用，7TV 表情保持原样，后台标签页会自行暂停。

在真实聊天中运行的样子：https://www.youtube.com/watch?v=NoGJeUrwy9o

功能一览

• 43 种语言，包含从右向左书写的语言（阿拉伯语、希伯来语、波斯语），并区分地区变体（巴西葡萄牙语、繁体中文）。
• 开箱即用，使用 Google 翻译免费翻译，不需要密钥，也不需要账号。
• 用你自己的 DeepL API 密钥获得更好的欧洲语言译文。DeepL 会收到最近的聊天内容作为上下文，因此措辞贴合对话。
• 自动备用：一个引擎失败时，由 MyMemory 或 Lingva 接手。顺序由你决定。
• 四种显示方式：在原文下方、与原文同一行、在原文之后以小号斜体显示，或仅在鼠标悬停时显示。悬停模式在你指向某条消息之前不翻译任何内容，在快速滚动的聊天中大约能把用量降到十分之一。
• 过滤：跳过机器人，屏蔽用户或频道，隐藏包含你所选词语的行（对付 !命令 刷屏很方便），或只翻译你想要的语言。
• 表情、提及、链接和刷屏 emoji 在发送前就会被剥离，不会浪费额度去翻译「kkkkkk」。
• 按你的喜好调整：文字大小、行距、字体、强调色、深色或浅色聊天、按频道记住的阅读语言、键盘快捷键。
• 界面支持 10 种语言：英语、西班牙语、法语、葡萄牙语、土耳其语、俄语、阿拉伯语、中文、日语和韩语。

什么会离开你的浏览器

聊天文本只发送给你选择的翻译引擎。使用 Google、MyMemory 或 Lingva 时，发送的只有每条消息的文本，别无其他：不包括频道，也不包括是谁说的。使用 DeepL 时，最近几行聊天会作为上下文一并发送，附带发言者的名字，让译文贴合对话。这就是上面权限中“网站内容”一项的含义，也是它的全部含义。没有账号，没有分析统计，也没有我的服务器：扩展只与 Kick、你选择的引擎，以及 GitHub 发布页面通信（用于告知你有新版本），而最后这个请求不携带任何内容。
