Kick Chat Translator は、Kick 用の無料ライブチャット翻訳拡張機能です。どの配信のチャットも自分の言語で読み、チャンネルの言語で返信できます。すべてチャット欄の中で完結します。

トルコ語、スペイン語、ロシア語、アラビア語の配信を見ていて、チャットについていけないことはありませんか？インストールして配信を開くだけで、届いたメッセージの真下にその場で翻訳が付きます。アカウントも API キーも要らず、設定することもありません。

使い方

1. Kick の配信をどれでも開きます。チャット上部の緑のバーが、翻訳機能がオンであることを示します。
2. 新しいメッセージごとに、その下にブラウザの言語での翻訳が付きます。
3. 自分の言語で返信を打ちます。チャンネルの言語でのプレビューが表示されるので、Tab を押すかクリックしてから送信します。

チャンネルの言語は Kick から読み取り、どちらの言語も設定で変更できます。ライブ配信でも VOD の録画でも動き、7TV のエモートはそのまま残し、バックグラウンドのタブでは自動で一時停止します。

主な機能

• 43言語に対応。右から左に書く言語（アラビア語、ヘブライ語、ペルシア語）も含み、地域変種（ブラジルポルトガル語、繁体字中国語）も区別して扱います。
• Google 翻訳で、インストールしてすぐ無料で使えます。キーもアカウントも要りません。
• 自分の DeepL API キーを使うと、ヨーロッパ言語の品質が上がります。DeepL には直近のチャットの発言も文脈として渡すので、言い回しが会話に沿います。
• Chrome と Edge 138 以降では、パソコンが対応していれば端末内で翻訳できます。オフラインで、上限なしで、チャットが端末から出ることはありません。
• 自動フォールバック：あるエンジンが失敗すると、MyMemory か Lingva が引き継ぎます。順番は自分で決められます。
• 四つの表示スタイル：メッセージの下、同じ行、後ろに小さめの斜体、またはカーソルを乗せたときだけ。カーソル表示モードはメッセージを指すまで何も翻訳しないので、速いチャットでは使用量がおよそ10分の1になります。
• フィルター：ボットを飛ばす、ユーザーやチャンネルをミュートする、選んだ言葉を含む行を隠す（!コマンドの連投対策に便利）、翻訳したい言語だけを翻訳する。
• エモート、メンション、リンク、絵文字の連投は送信前に取り除かれるので、「kkkkkk」の翻訳に何も費やしません。
• 自分好みに：文字サイズ、行間、書体、アクセントカラー、ダークまたはライトのチャット、チャンネルごとに覚える読む言語、キーボードショートカット。
• インターフェースは10言語：英語、スペイン語、フランス語、ポルトガル語、トルコ語、ロシア語、アラビア語、中国語、日本語、韓国語。

プライバシー

アカウントも、アクセス解析も、私のサーバーもありません。チャットの文章は、あなたが選んだ翻訳エンジンにだけ送られます。Google、MyMemory、Lingva の場合は、各メッセージの本文だけで、ほかには何も送りません。DeepL の場合は、翻訳が会話に沿うよう、直近の数行のチャットを、書いた人の名前と一緒に文脈として送ります。見ているチャンネルは決して送られず、端末内翻訳なら何もパソコンから出ません。

権限をわかりやすく言うと、設定と翻訳キャッシュのための保存領域、チャットに翻訳を表示するための kick.com へのアクセス、呼び出しうるエンジン（Google、DeepL、MyMemory、Lingva）へのアクセス、見ている間に翻訳機能を待機させておくためのタイマー、そしてインストール時や更新時に、すでに開いている Kick のタブへ自分のスクリプトを読み込み直す権限です。これにより、ページを再読み込みしなくても翻訳が続きます。また、新しいバージョンがあることを知らせるために GitHub のリリースページを読みますが、その通信では何も送りません。
