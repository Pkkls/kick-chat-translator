Kick Chat Translator என்பது Kick-க்கான இலவச நேரடி அரட்டை மொழிபெயர்ப்பு நீட்சி. எந்த ஸ்ட்ரீமின் அரட்டையையும் உங்கள் சொந்த மொழியில் படியுங்கள், சேனலின் மொழியில் அரட்டைக்குள்ளேயே பதிலளியுங்கள்.

துருக்கிய, ஸ்பானிய, ரஷ்ய அல்லது அரபு ஸ்ட்ரீமைப் பார்க்கிறீர்கள், ஆனால் அரட்டை புரியவில்லையா? நிறுவி, ஸ்ட்ரீமைத் திறந்தால் போதும்: ஒவ்வொரு செய்தியும் வரும்போதே அதன் கீழே மொழிபெயர்ப்பு தெரியும். கணக்கு இல்லை, API key இல்லை, எந்த அமைப்பும் தேவையில்லை.

எப்படி வேலை செய்கிறது

1. ஏதேனும் Kick ஸ்ட்ரீமைத் திறங்கள். அரட்டையின் மேலே உள்ள பச்சைப் பட்டை மொழிபெயர்ப்பாளர் இயங்குவதைக் காட்டும்.
2. ஒவ்வொரு புதிய செய்திக்கும் கீழே, உங்கள் உலாவியின் மொழியில் அதன் மொழிபெயர்ப்பு வரும்.
3. உங்கள் மொழியில் பதிலை எழுதுங்கள். சேனலின் மொழியில் அதன் முன்னோட்டம் தெரியும்: Tab அழுத்துங்கள் அல்லது அதைக் கிளிக் செய்யுங்கள், பிறகு அனுப்புங்கள்.

சேனலின் மொழி Kick-இலிருந்தே எடுக்கப்படுகிறது, இரண்டு மொழிகளையும் அமைப்புகளில் மாற்றலாம். நேரலை ஸ்ட்ரீம்களிலும் VOD மறுஒளிபரப்புகளிலும் வேலை செய்யும், 7TV எமோட்களை அப்படியே வைத்திருக்கும், பின்னணி டேப்களில் தானாக இடைநிறுத்திக்கொள்ளும்.

உங்களுக்குக் கிடைப்பவை

• 43 மொழிகள், வலமிருந்து இடமாக எழுதும் மொழிகளும் (அரபு, ஹீப்ரு, பாரசீகம்) உட்பட; பிராந்திய வேறுபாடுகள் தனியாக வைக்கப்படுகின்றன (பிரேசிலிய போர்த்துகீசியம், பாரம்பரிய சீனம்).
• Google Translate மூலம் உடனே இலவசம், key இல்லை, கணக்கு இல்லை.
• உங்கள் சொந்த DeepL API key இருந்தால் ஐரோப்பிய மொழிகளில் சிறந்த மொழிபெயர்ப்பு. சமீபத்திய அரட்டை வரிகளை DeepL சூழலாகப் பெறுவதால், சொற்கள் உரையாடலுக்குப் பொருந்தும்.
• Chrome மற்றும் Edge 138+ இல் உங்கள் கணினி ஆதரித்தால் சாதனத்திலேயே மொழிபெயர்ப்பு: ஆஃப்லைன், வரம்பின்றி, அரட்டை உங்கள் கணினியை விட்டு வெளியேறாது.
• தானியங்கி மாற்று வழி: ஒரு இயந்திரம் தோல்வியுற்றால் MyMemory அல்லது Lingva பொறுப்பேற்கும். வரிசையை நீங்களே தேர்வு செய்யலாம்.
• நான்கு காட்சி பாணிகள்: செய்திக்குக் கீழே, அதே வரியில், அதன் பின்னால் சிறிய சாய்வெழுத்தில், அல்லது கர்சரை வைக்கும்போது மட்டும். வேகமான அரட்டையில் கர்சர் பயன்முறை பயன்பாட்டை ஏறக்குறைய பத்து மடங்கு குறைக்கும்; ஒரு செய்தியின் மேல் சுட்டும் வரை எதையும் மொழிபெயர்க்காது.
• வடிகட்டிகள்: போட்களைத் தவிர்க்கலாம், பயனர்களை அல்லது சேனல்களை முடக்கலாம், நீங்கள் தேர்ந்த சொல் உள்ள வரிகளை மறைக்கலாம் (!command ஸ்பாமுக்கு உதவும்), அல்லது நீங்கள் விரும்பும் மொழிகளை மட்டும் மொழிபெயர்க்கலாம்.
• எமோட்கள், குறிப்பிடல்கள், இணைப்புகள், எமோஜி ஸ்பாம் ஆகியவை எதுவும் அனுப்பப்படும் முன்பே நீக்கப்படும்; அதனால் "kkkkkk" ஐ மொழிபெயர்க்க எதுவும் செலவாகாது.
• உங்கள் விருப்பப்படி மாற்றுங்கள்: எழுத்தின் அளவு, வரி இடைவெளி, எழுத்துரு, முக்கிய நிறம், இருண்ட அல்லது ஒளிர் அரட்டை, ஒவ்வொரு சேனலுக்கும் நினைவில் வைக்கப்படும் வாசிப்பு மொழி, விசைப்பலகை குறுக்குவழிகள்.
• 10 மொழிகளில் இடைமுகம்: ஆங்கிலம், ஸ்பானியம், பிரெஞ்சு, போர்த்துகீசியம், துருக்கியம், ரஷ்யம், அரபு, சீனம், ஜப்பானியம், கொரியம்.

தனியுரிமை

கணக்கு இல்லை, பகுப்பாய்வு இல்லை, என் சர்வர் இல்லை. அரட்டை உரை நீங்கள் தேர்ந்த மொழிபெயர்ப்பு இயந்திரத்திற்கு மட்டுமே செல்லும். Google, MyMemory அல்லது Lingva என்றால், ஒவ்வொரு செய்தியின் உரை மட்டுமே செல்லும், வேறெதுவும் இல்லை. DeepL என்றால், மொழிபெயர்ப்பு உரையாடலுக்குப் பொருந்துவதற்காக, கடைசி சில அரட்டை வரிகள் அவற்றை எழுதியவர்களின் பெயர்களுடன் சூழலாகச் செல்லும். நீங்கள் பார்க்கும் சேனல் ஒருபோதும் அனுப்பப்படாது, சாதனத்திலேயே மொழிபெயர்ப்பில் எதுவும் உங்கள் கணினியை விட்டு வெளியேறாது.

அனுமதிகள், எளிய சொற்களில்: உங்கள் அமைப்புகளுக்கும் மொழிபெயர்ப்பு தற்காலிகச் சேமிப்புக்கும் storage; அரட்டையில் மொழிபெயர்ப்புகளைக் காட்ட kick.com அணுகல்; அது அழைக்கக்கூடிய இயந்திரங்களுக்கான அணுகல் (Google, DeepL, MyMemory, Lingva); நீங்கள் பார்க்கும்போது மொழிபெயர்ப்பாளர் தயாராக இருக்க ஒரு எழுப்பு டைமர்; நிறுவும்போதோ புதுப்பிக்கும்போதோ ஏற்கெனவே திறந்திருக்கும் Kick டேப்களில் தன் ஸ்கிரிப்டை மீண்டும் ஏற்றும் உரிமை, இதனால் அவை புதுப்பிக்காமலேயே மொழிபெயர்ப்பைத் தொடரும். புதிய பதிப்பு இருப்பதை உங்களுக்குச் சொல்ல GitHub releases பக்கத்தையும் படிக்கும்; அந்தக் கோரிக்கையுடன் எதுவும் அனுப்பாது.
