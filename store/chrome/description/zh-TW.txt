Kick Chat Translator 是一款免費的 Kick 聊天室翻譯擴充功能。用你自己的語言閱讀任何實況的聊天室，並直接在聊天室裡用頻道的語言回覆。

正在看土耳其語、西班牙語、俄語或阿拉伯語的實況，卻看不懂聊天室？安裝後打開實況，每則訊息一出現，正下方就會顯示它的翻譯。不需要帳號，不需要 API 金鑰，什麼都不用設定。

使用方式

1. 打開任何 Kick 實況。聊天室上方的綠色列表示翻譯功能已啟用。
2. 每則新訊息下方都會顯示翻譯，語言為你瀏覽器的語言。
3. 用你自己的語言輸入回覆。預覽會以頻道的語言顯示：按 Tab 或點一下預覽，然後送出。

頻道的語言直接從 Kick 讀取，兩種語言都可以在設定中更改。實況和 VOD 重播都能用，7TV 表情保持原樣，在背景分頁時會自動暫停。

功能一覽

• 43 種語言，包含由右至左書寫的語言（阿拉伯語、希伯來語、波斯語），並區分各地區變體（巴西葡萄牙語、繁體中文）。
• 開箱即用，透過 Google Translate 免費翻譯，不需要金鑰，也不需要帳號。
• 使用你自己的 DeepL API 金鑰，歐洲語言的翻譯更好。DeepL 會收到最近的聊天內容作為上下文，讓用詞貼合對話。
• 在 Chrome 和 Edge 138 以上版本中，只要你的電腦支援，就能在裝置上翻譯：離線、無上限，聊天內容不會離開你的電腦。
• 自動備援：一個引擎失敗時，由 MyMemory 或 Lingva 接手。順序由你決定。
• 四種顯示方式：在訊息下方、與訊息同一行、在訊息後以小字斜體顯示，或只在滑鼠移上去時顯示。懸停模式在你指向某則訊息之前不會翻譯任何內容，在聊天室刷得很快時，用量大約可降為十分之一。
• 過濾：略過機器人、封鎖使用者或頻道、隱藏含有你指定字詞的訊息（對付 !command 洗版很好用），或只翻譯你想要的語言。
• 表情、提及、連結和洗版的 emoji 會在送出前先移除，所以不會浪費額度去翻譯「kkkkkk」。
• 照你的喜好調整：文字大小、行距、字型、強調色、深色或淺色聊天室、依頻道記住的閱讀語言、鍵盤快速鍵。
• 介面同樣支援這 43 種語言，包含由右至左書寫的語言，可從顯示各語言旗幟的選單中挑選。

隱私

沒有帳號，也沒有我的伺服器。除非你同意，否則沒有分析統計；同意後每天只傳一次匿名計數：使用的引擎、錯誤與速度，絕不包含你的訊息、名稱或頻道。聊天文字只會傳給你選擇的翻譯引擎。使用 Google、MyMemory 或 Lingva 時，傳出的只有每則訊息的文字，沒有其他。使用 DeepL 時，最近幾行聊天內容會作為上下文一併傳出，並附上發言者的名稱，讓翻譯貼合對話。你正在看的頻道從不會被傳出；使用裝置上翻譯時，任何內容都不會離開你的電腦。

權限的白話說明：儲存空間權限，用來保存你的設定和翻譯快取；存取 kick.com，用來在聊天室中顯示翻譯；存取它可能呼叫的引擎（Google、DeepL、MyMemory 和 Lingva）；一個喚醒計時器，讓翻譯功能在你觀看時保持待命；以及在安裝或更新時，把自己的指令碼重新載入已開啟的 Kick 分頁的權限，這樣不必重新整理就能繼續翻譯。它也會讀取 GitHub 的發行頁面，在有新版本時通知你，該請求不會帶任何內容。
