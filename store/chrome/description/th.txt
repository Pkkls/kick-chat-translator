Kick Chat Translator คือส่วนขยายแปลแชทสดฟรีสำหรับ Kick อ่านแชทของสตรีมไหนก็ได้เป็นภาษาของคุณเอง แล้วตอบกลับเป็นภาษาของช่องได้ในแชทเลย

ดูสตรีมภาษาตุรกี สเปน รัสเซีย หรืออาหรับ แล้วตามแชทไม่ทัน? แค่ติดตั้งแล้วเปิดสตรีม ทุกข้อความจะมีคำแปลโผล่ใต้ข้อความทันทีที่เข้ามา ไม่ต้องมีบัญชี ไม่ต้องใช้ API key ไม่ต้องตั้งค่าอะไรเลย

ใช้งานอย่างไร

1. เปิดสตรีม Kick ไหนก็ได้ แถบสีเขียวด้านบนของแชทแสดงว่าตัวแปลทำงานอยู่
2. ทุกข้อความใหม่จะมีคำแปลอยู่ด้านล่าง เป็นภาษาของเบราว์เซอร์คุณ
3. พิมพ์ตอบเป็นภาษาของคุณ ระบบจะแสดงตัวอย่างเป็นภาษาของช่อง กด Tab หรือคลิกที่ตัวอย่าง แล้วส่งได้เลย

ภาษาของช่องอ่านมาจาก Kick โดยตรง และเปลี่ยนได้ทั้งสองภาษาในการตั้งค่า ใช้ได้ทั้งกับสตรีมสดและวิดีโอย้อนหลัง (VOD) คงอีโมต 7TV ไว้ตามเดิม และหยุดทำงานเองเมื่ออยู่ในแท็บเบื้องหลัง

สิ่งที่คุณจะได้

• 43 ภาษา รวมภาษาที่เขียนจากขวาไปซ้าย (อาหรับ ฮีบรู เปอร์เซีย) และแยกสำเนียงตามภูมิภาคไว้ต่างหาก (โปรตุเกสแบบบราซิล จีนตัวเต็ม)
• ใช้ฟรีได้ทันทีด้วย Google Translate ไม่ต้องมี key ไม่ต้องมีบัญชี
• ภาษายุโรปแปลได้ดีขึ้นเมื่อใช้ DeepL API key ของคุณเอง DeepL จะได้รับบรรทัดแชทล่าสุดเป็นบริบท ถ้อยคำจึงเข้ากับบทสนทนา
• แปลบนเครื่องใน Chrome และ Edge 138+ เมื่อคอมพิวเตอร์รองรับ ใช้ออฟไลน์ได้ ไม่จำกัด และแชทไม่ออกจากเครื่องของคุณ
• สำรองอัตโนมัติ: เมื่อเอนจินหนึ่งใช้ไม่ได้ MyMemory หรือ Lingva จะรับช่วงต่อ คุณเลือกลำดับได้เอง
• สี่รูปแบบการแสดงผล: ใต้ข้อความ บรรทัดเดียวกัน ตัวเอียงเล็กต่อท้ายข้อความ หรือเฉพาะตอนที่เอาเมาส์ไปชี้ โหมดชี้เมาส์จะไม่แปลอะไรเลยจนกว่าคุณจะชี้ที่ข้อความ ช่วยลดการใช้งานลงราวสิบเท่าในแชทที่วิ่งเร็ว
• ตัวกรอง: ข้ามบอต ปิดเสียงผู้ใช้หรือช่อง ซ่อนบรรทัดที่มีคำที่คุณเลือก (ช่วยรับมือสแปม !command) หรือแปลเฉพาะภาษาที่คุณต้องการ
• อีโมต การกล่าวถึง ลิงก์ และสแปมอีโมจิจะถูกตัดออกก่อนส่งอะไรไปแปล จึงไม่เสียโควตาไปกับการแปล "kkkkkk"
• ปรับให้เป็นของคุณ: ขนาดตัวอักษร ระยะห่างบรรทัด แบบอักษร สีเน้น แชทโหมดมืดหรือสว่าง ภาษาที่อ่านซึ่งจำแยกตามแต่ละช่อง และคีย์ลัด
• หน้าตาส่วนขยายมีครบทั้ง 43 ภาษาเดียวกัน รวมภาษาที่เขียนจากขวาไปซ้าย เลือกได้จากเมนูที่แสดงธงของแต่ละภาษา

ความเป็นส่วนตัว

ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ของผม และไม่มีระบบวิเคราะห์ เว้นแต่คุณยินยอมให้นับแบบไม่ระบุตัวตนวันละครั้งเรื่องเอนจินที่ใช้ ข้อผิดพลาด และความเร็ว ไม่มีข้อความ ชื่อ หรือช่องของคุณเด็ดขาด ข้อความแชทจะไปที่เอนจินแปลที่คุณเลือกเท่านั้น หากใช้ Google, MyMemory หรือ Lingva จะส่งเฉพาะข้อความของแต่ละข้อความและไม่มีอย่างอื่น หากใช้ DeepL จะส่งบรรทัดแชทล่าสุดไม่กี่บรรทัดไปเป็นบริบทพร้อมชื่อของคนที่เขียน เพื่อให้คำแปลเข้ากับบทสนทนา ช่องที่คุณดูจะไม่ถูกส่งไปเลย และถ้าแปลบนเครื่อง จะไม่มีอะไรออกจากคอมพิวเตอร์คุณ

สิทธิ์ที่ขอ พูดให้เข้าใจง่าย: storage สำหรับการตั้งค่าและแคชคำแปล การเข้าถึง kick.com เพื่อแสดงคำแปลในแชท การเข้าถึงเอนจินที่เรียกใช้ได้ (Google, DeepL, MyMemory และ Lingva) ตัวตั้งเวลาปลุกเพื่อให้ตัวแปลพร้อมอยู่ขณะที่คุณดู และสิทธิ์โหลดสคริปต์ของตัวเองซ้ำในแท็บ Kick ที่เปิดอยู่แล้วตอนติดตั้งหรืออัปเดต เพื่อให้แปลต่อได้โดยไม่ต้องรีเฟรช นอกจากนี้ยังอ่านหน้า GitHub releases เพื่อแจ้งคุณเมื่อมีเวอร์ชันใหม่ โดยไม่ส่งอะไรไปกับคำขอนั้น
