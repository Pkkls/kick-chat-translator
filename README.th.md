## ใช้งานอย่างไร

1. ติดตั้งแล้วเปิดสตรีม Kick ช่องไหนก็ได้ แถบสีเขียวด้านบนของแชทบอกว่าส่วนขยายทำงานอยู่
2. ทุกข้อความจะมีคำแปลขึ้นอยู่ข้างใต้ทันทีที่เข้ามา เป็นภาษาเดียวกับเบราว์เซอร์ของคุณ ทั้งสตรีมสดและ
   VOD ย้อนหลัง
3. พิมพ์ตอบเป็นภาษาของคุณ ตัวอย่างเหนือช่องแชทจะโชว์ข้อความนั้นเป็นภาษาของช่อง:
   กด Tab หรือคลิกที่ตัวอย่าง ข้อความที่แปลแล้วจะเข้าไปแทนที่สิ่งที่พิมพ์

ภาษาของช่องอ่านมาจาก Kick โดยตรง จึงไม่ต้องตั้งค่าอะไร ทั้งสองภาษาเปลี่ยนได้ในการตั้งค่า
และจำภาษาที่อ่านแยกตามช่องได้

## มีอะไรบ้าง

- **43 ภาษา** รวมภาษาที่เขียนจากขวาไปซ้าย (อาหรับ ฮีบรู เปอร์เซีย) และแยกสำเนียงท้องถิ่นไว้ต่างหาก
  (โปรตุเกสแบบบราซิลกับแบบยุโรป จีนตัวย่อกับจีนตัวเต็ม กวางตุ้ง)
- **ตัวส่วนขยายก็พูดได้ทุกภาษาเหมือนกัน**: การตั้งค่า ป็อปอัป และแถบแชทมีครบทั้ง 43 ภาษา เลือกจากเมนูที่มีธงประเทศ
- **ฟรีตั้งแต่ติดตั้ง** ด้วย Google Translate ใส่คีย์ DeepL ฟรีของคุณเองเพื่อให้ภาษายุโรปแปลได้ดีขึ้น
  ถ้าเอนจินตัวไหนล่ม MyMemory กับ Lingva จะเข้ามารับช่วงต่อ
- **แปลในเครื่อง** บน Chrome และ Edge ที่เบราว์เซอร์รองรับ: 22 ms แทนที่จะเป็น 1.6 วินาที
  และข้อความไม่ออกจากคอมพิวเตอร์ของคุณเลย
- **ตัวกรอง**: ข้ามบอต ปิดเสียงผู้ใช้หรือช่อง ซ่อนบรรทัดที่มีคำที่กำหนด
  แปลเฉพาะภาษาที่คุณเลือก
- **สร้างมาสำหรับแชทที่วิ่งเร็ว**: อีโมต 7TV คงไว้ตามเดิม สแปมอีโมจิและลิงก์ถูกตัดออกก่อนส่งไปแปล
  มีอภิธานศัพท์สำหรับชื่อที่เอนจินแปลเพี้ยน และมีแคชคำแปล
- **รูปแบบการแสดงผลสี่แบบ**: ใต้ข้อความ ในบรรทัดเดียวกัน แทนที่ข้อความเดิม หรือแสดงเฉพาะตอนเอาเมาส์ชี้
- **หยุดแค่ช่องเดียว** จากแถบแชทโดยไม่กระทบช่องอื่น เปลี่ยนช่องหรืออัปเดตส่วนขยาย
  แท็บที่เปิดอยู่ก็แปลต่อได้ ไม่ต้องรีโหลด
- Chrome, Brave, Edge และ Firefox

## เอนจินแปลภาษา

ผู้ให้บริการสี่ราย ต่อกันเป็นลูกโซ่: ตัวไหนล่ม ตัวถัดไปรับช่วงต่อ ลำดับกำหนดเองได้

| ผู้ให้บริการ | คีย์ | หมายเหตุ |
|---|---|---|
| Google | ไม่ต้องใช้ | ค่าเริ่มต้น ใช้ได้ทันที |
| DeepL | ฟรี | คุณภาพดีที่สุด มี[คีย์ฟรี](https://www.deepl.com/pro-api) 1 ล้านตัวอักษรต่อเดือน |
| MyMemory | ไม่ต้องใช้ | ตัวสำรอง |
| Lingva | ไม่ต้องใช้ | ตัวสำรอง ใช้อินสแตนซ์สาธารณะ เว้นแต่คุณจะชี้ไปที่ของตัวเอง |

ตัวแปลในตัวของ Chromium เร็วกว่าทุกตัวข้างบน วัดบนช่องสดจริง: 22 ms ตั้งแต่ข้อความขึ้นจนคำแปลโผล่บนจอ
เทียบกับ 1618 ms ผ่านลูกโซ่คลาวด์ โดยไม่ใช้เครือข่ายและไม่มีโควตา Chrome และ Edge เวอร์ชัน 138 ขึ้นไป
เปิดใช้ได้ แต่ไม่ใช่ทุกเครื่อง และแต่ละคู่ภาษาต้องดาวน์โหลดโมเดลหนึ่งครั้ง
ด้วยการคลิกหนึ่งทีจากแถบ Firefox ไม่มีฟีเจอร์นี้ ที่ไหนไม่มี
ลูกโซ่คลาวด์จะเข้ามารับช่วงและทุกอย่างยังทำงานต่อได้

## การตั้งค่า

คลิกรูปเฟืองบนแถบแชท หรือคลิกขวาที่ไอคอนส่วนขยายแล้วเลือก ตัวเลือก

- **บริการ** (Providers): ลำดับเอนจิน คีย์ DeepL ของคุณ และโหมด: ในเครื่องก่อน คลาวด์ก่อน หรือเฉพาะในเครื่อง
- **การแสดงผล** (Display): ภาษาปลายทาง รูปแบบการแสดง ข้อความต้นฉบับและป้ายภาษา ขนาดตัวอักษร ระยะห่างบรรทัด
  แบบอักษร สีเน้น ธีมแชท ตัวอย่างข้อความที่พิมพ์ และสิ่งที่เกิดขึ้นเมื่อคลิกมัน
- **ตัวกรอง** (Filters): บอต ผู้ใช้ ช่อง คำสำคัญ ภาษาต้นทาง และอภิธานศัพท์สำหรับคำแทนที่
- **ขั้นสูง** (Advanced): ขนาดและอายุแคช การแปลพร้อมกัน ขีดจำกัดต่อช่อง สำรองและกู้คืนข้อมูล
- **กิจกรรม** (Activity): จำนวนข้อความที่แปล แคชที่พบ ทุกภาษาที่เจอในแชท และเหตุผลที่ 50
  บรรทัดล่าสุดถูกแปลหรือถูกข้าม
- **คีย์ลัด**: Alt+T เปิดหรือปิดการแปลแชท Alt+W เปิดหรือปิดตัวอย่างข้อความที่พิมพ์
- ปุ่มภาษาบนแถบการกระทำของแชท: คลิกครั้งเดียวสลับระหว่างภาษาของช่องกับ
  ภาษาที่เลือกล่าสุด กดค้างเพื่อเปิดรายการ พิมพ์สองตัวอักษรเพื่อกรอง

## คำถามที่พบบ่อย

**ข้อความไม่ถูกแปล**
เปิดแท็บ กิจกรรม ในการตั้งค่าแล้วกด "อ่านการตัดสิน": มันจะแสดง 50 บรรทัดล่าสุดพร้อมบอกว่า
แต่ละบรรทัดถูกแปลหรือถูกข้ามเพราะอะไร บรรทัดที่ถูกข้ามส่วนใหญ่ตั้งใจข้าม ในสตรีมสดรอบหนึ่ง 213
จาก 234 บรรทัดเป็นผู้ใช้คนเดิมพิมพ์ซ้ำ 9 บรรทัดสั้นเกินไป 7 บรรทัดมีแต่อีโมจิหรือหัวเราะ และ 1 บรรทัด
เป็นภาษาที่คุณอ่านอยู่แล้ว ถ้าแท็บไม่แสดงอะไรเลย แปลว่าส่วนขยายมองไม่เห็นแชท:
ช่วยเปิด issue ให้หน่อย

**แถบสีเขียวหายไป**
รีเฟรชหน้า ถ้ายังเป็นอีก เปิด [issue](https://github.com/Pkkls/kick-chat-translator/issues)
พร้อมบอกช่องและสิ่งที่ทำก่อนหน้านั้น

**ทำอย่างไรให้แปลได้ดีขึ้น**
ใส่คีย์ DeepL ฟรีในการตั้งค่า แพ็กเกจฟรีให้หนึ่งล้านตัวอักษรต่อเดือน และ DeepL จะถูกใช้

## มีอะไรใหม่

ในรุ่น 3.2.0:

- การตั้งค่า ป็อปอัป และแถบแชทพูดได้ครบทั้ง 43 ภาษาที่ส่วนขยายแปลให้ ไม่ใช่แค่ 10 โดยฮีบรูและเปอร์เซียเขียนจากขวาไปซ้ายเหมือนอาหรับ
- สิบภาษาที่มีอยู่เดิมถูกเขียนใหม่ให้อ่านเหมือนเขียนด้วยภาษานั้นจริง ๆ ไม่ใช่แปลตรงตัวจากอังกฤษ
- เมนูภาษาของส่วนขยายแสดงธงของแต่ละภาษา และใช้ด้วยคีย์บอร์ดได้

ทุกรุ่น พร้อมสิ่งที่เปลี่ยนและตัวเลขที่วัดได้:
[Releases](https://github.com/Pkkls/kick-chat-translator/releases) และ [CHANGELOG.md](CHANGELOG.md)

## การพัฒนา

```bash
git clone https://github.com/Pkkls/kick-chat-translator.git
cd kick-chat-translator
npm ci
npm run release:check    # typecheck, lint, unit tests, build: the gate every package goes through
npm run build:firefox    # Firefox build, same dist/ folder
npm run package:all      # both zips, in release/
npm run dev              # HMR
```

บิลด์ทำซ้ำได้: คอมมิตเดียวกันให้ไฟล์ zip ที่ตรงกันทุกไบต์บนทุกเครื่อง ตรวจโดยการบิลด์
`git archive` ของแท็กในโฟลเดอร์ว่างแล้วเทียบแฮช

นอกจากยูนิตเทสต์ ยังมี 42 gate แบบออฟไลน์ที่โหลดส่วนขยายที่บิลด์แล้วเข้าเบราว์เซอร์จริง สั่งงานมัน แล้วตรวจว่า
มันทำอะไร โดยหน้าเว็บเสิร์ฟในเครื่องและเอนจินแปลตอบกลับในเครื่อง ต้องใช้
Playwright ซึ่งตั้งใจไม่ใส่เป็น dependency: ชี้ `UX_KIT` ไปที่โฟลเดอร์ที่ `node_modules` มีมันอยู่
หรือรัน `npm i -D playwright`

```bash
node test/e2e/run-gates.mjs --headless                  # all 42, no window
node test/e2e/store-shots-fixture.mjs --lang=ja         # the store screenshots, in one listing language
node test/e2e/store-shots-fixture.mjs --gif             # English store screenshots, the README images and this GIF
```

สตริงของหน้าตาส่วนขยายอยู่ใน `src/shared/i18n/` (ป็อปอัปและตัวเลือก ใช้ข้อความภาษาอังกฤษเป็นคีย์) และ
`src/content/i18n/` (แถบแชท ใช้ id เป็นคีย์ โดยมีข้อความภาษาอังกฤษเป็นตัวสำรอง) หนึ่งไฟล์ต่อภาษา
เทสต์บังคับให้ทุกไฟล์มีคีย์ครบชุด ข้อความของสโตร์
อยู่ใน [store/](store/) และการปล่อยรุ่นคือการติดแท็กเวอร์ชัน: CI จะบิลด์ ตรวจ และเผยแพร่ไปทั้งสอง
สโตร์

Stack: Manifest V3, Vite, TypeScript, Preact, Tailwind

## โปรเจกต์ที่เกี่ยวข้อง

- [kick-ad-blocker](https://github.com/Pkkls/kick-ad-blocker) บล็อกโฆษณา pre-roll และโฆษณาซ้อนทับของ Kick
- [kick-core](https://github.com/Pkkls/kick-core) ไคลเอนต์เกตเวย์เรียลไทม์ที่ส่วนขยายเหล่านี้ใช้ร่วมกัน
- [kickbus](https://github.com/Pkkls/kickbus) เว็บฮุก Kick อย่างเป็นทางการที่ส่งต่อไปยังบอตในเครื่องผ่าน SSE
- [kick-drops-miner](https://github.com/Pkkls/kick-drops-miner) แอป Windows ที่สะสมเวลารับชมสำหรับ Kick drops
